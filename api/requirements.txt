# Dependencies for the Vercel Python function — a COPY of the root

# @vercel/python looks in first. Relying on the root copy alone left the
# function with no FastAPI at all, which crashed it before it could report why.
#

# in google-api-python-client and its dependency tree, which is tens of
# megabytes against a 250 MB function bundle — and it is useless here anyway,
# because a serverless container has nowhere durable to put the images it
# downloads. Those imports are all inside functions in backend/images.py, so
# leaving the packages out costs nothing until someone calls the Drive endpoint,
# which then reports that Drive is unavailable.
#
